# My Benz Is in Tokens

あそこにベンツが停まっていますね？

あなたがAIにチャットを送らなければ、
あれくらい買えたかもしれません。


このプロダクトは、その「あれくらい」を、自販機の飲み物と家賃のあいだで測るための、GitHub Copilot キャンバスです。名前は `thinking-viz`。画面上では「トークン料金」と名乗ります。請求書ではありません。墓誌でもありません。ただ、いま消えた円が、何本の缶チューハイだったかを告げる装置です。

## 何をするか

あなたがメッセージを送ると、キャンバスは勝手に開きます。閉じていても、次の一文でまた現れます。トークンは忘れません。キャンバスだけが、ときどき眠ります。

画面には三つの窓があります。

1. **予算**  
   円を入力して保存します。保存先は `~/.copilot/extensions/thinking-viz/artifacts/budget.json` です。このリポジトリには入れません。家計簿を Git に上げる人は、もうベンツを諦めた人です。

2. **いま（この質問）**  
   いまの一文で消えた円です。入力・出力・キャッシュのトークン数と、モデル名が小さく並びます。円の横にはドルが小さく付きます。ドルは現実で、円は生活です。

3. **このチャットの合計**  
   この作業場で積み上がった円です。`files/token-cost.json` に残ります。チャットを閉じても、トークンは帰宅しません。

予算を超えると、バーが赤くなり、警告文が段階的に悪化します。擦り傷から始まり、自販機、缶ビール、電気代、定期、家賃、保証人、そして家を失う直前まで行きます。家を失ってからも、キャンバスは開き続けます。

## 円の作り方

トークンは、次のうちいちばん高い見積もりをドルにし、為替で円にします。

| 原料 | 単価 |
| --- | --- |
| 入力 | $2.5 / 100万トークン |
| 出力 | $10 / 100万トークン |
| キャッシュ読み | $0.25 / 100万トークン |
| Premium / Nano AIU | $0.04 |

為替は [Frankfurter](https://api.frankfurter.app) の USD/JPY です。取れなければ 148 円で計算します。148 は、誰かがどこかで決めた、静かな定数です。

これは概算です。Copilot の請求書そのものではありません。ベンツの見積もりでもありません。見積もりが正しければ、あなたはもう乗っていません。

## 買えるもの

円は、まず生活に翻訳されます。高いものから順に、いまの金額で何単位買えたかを出します。

| 品目 | 単価 |
| --- | --- |
| 自販機の飲み物 | ¥160 / 本 |
| 缶チューハイ | ¥170 / 本 |
| ガソリン | ¥180 / L |
| 缶ビール | ¥250 / 本 |
| タバコ | ¥650 / 箱 |
| ランチ | ¥1,000 / 食 |

0.5 円未満は「誤差の範囲」です。自販機のボタンを押し損ねた程度、と書いてあります。160 円未満は、飲み物の何パーセントかです。まだ1本にも足りません。足りないうちが、いちばん幸福です。

同じ円を、ランチ・ガソリン・タバコ・自販機・缶ビール・缶チューハイでも同時に換算します。ベンツはカタログにありません。カタログに載せた瞬間、誰かが本当に買いそうだからです。

## インストール

ユーザー領域に置く場合:

```bash
mkdir -p ~/.copilot/extensions/thinking-viz
cp extension.mjs renderer.mjs catalog.mjs ~/.copilot/extensions/thinking-viz/
```

Copilot を再読み込みすると、キャンバスが使えます。再読み込みのあいだ、トークンは静かに待っています。あなただけが、待っていません。

## 内部

ローカルに HTTP サーバを立て、SSE で画面を更新します。ポートは空いている番号です。外には開きません。127.0.0.1 だけが、あなたの浪費を知っています。

キャンバス操作:

- `refresh` — いまの円換算と合計、予算の残りを返します
- `set_budget` — 予算を円で保存します

合計欄にはテスト用の円入力があります。未来の自分に、いまの自分を見せるための穴です。空に戻すと、本物の合計が戻ってきます。本物の合計は、たいてい、見たくありません。

同一の API 呼び出しは二度数えません。トークンは誠実です。あなたが同じ質問を二度送るのは、別の話です。

## 注意

円は概算です。  
予算はリポジトリの外にあります。  
ベンツは、まだあそこに停まっています。
